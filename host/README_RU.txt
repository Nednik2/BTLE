=====================================================================
  BLE-сниффер на HackRF (BTLE / btle_rx) — инструкция
=====================================================================

Папка с программами:
  C:\Users\Kel\Downloads\FIRMWARE_mayhem_nightly_n_261027\BLE\BTLE\host\build\btle-tools\src\

В ней должны лежать вместе:
  btle_wireshark.bat   — запуск живого просмотра в Wireshark
  btle_rx.exe          — сам сниффер
  btle_tx.exe          — передатчик (не нужен для приёма)
  libhackrf.dll, libusb-1.0.dll, libwinpthread-1.dll  — библиотеки
Переносить в другое место — только всей папкой.

Перед работой: на PortaPack включи режим HackRF, иначе ПК не увидит прибор.

---------------------------------------------------------------------
1. ЖИВОЙ ПРОСМОТР В WIRESHARK (основной режим)
---------------------------------------------------------------------
Двойной щелчок по btle_wireshark.bat — откроется консоль и Wireshark,
пакеты пойдут в реальном времени.

Из командной строки с параметрами:
  btle_wireshark.bat [канал] [LNA] [VGA]

  канал — 37, 38 или 39 (по умолчанию 37)
  LNA   — усиление предусилителя, 0..40 шаг 8 (по умолчанию 16)
  VGA   — усиление тракта, 0..62 шаг 2 (по умолчанию 20)

Примеры:
  btle_wireshark.bat              — канал 37, LNA 16, VGA 20
  btle_wireshark.bat 38           — канал 38
  btle_wireshark.bat 37 24 20     — слабый сигнал, подняли LNA до 24
  btle_wireshark.bat 37 8 20      — прибор рядом с источником, LNA 8

Усиление меняется только перезапуском — на ходу не регулируется.

ОСТАНОВКА: закрой окно ЧЁРНОЙ КОНСОЛИ (где работает btle_rx).
Закрыть только Wireshark мало — приём продолжится и займёт прибор.

---------------------------------------------------------------------
2. ЗАПИСЬ В ФАЙЛ (посмотреть позже)
---------------------------------------------------------------------
  btle_rx.exe -c 37 -l 16 -g 20 -s capture.pcap

Останови по Ctrl+C, затем открой capture.pcap в Wireshark.

---------------------------------------------------------------------
3. ПОДБОР УСИЛЕНИЯ
---------------------------------------------------------------------
  Пакетов мало или нет        -> поднимай LNA: 16 -> 24 -> 32
  Прибор вплотную к источнику -> снижай: LNA 0..8, VGA 10..20
  Много пакетов "Malformed"   -> признак перегрузки, снизь усиление

Эфир нестабилен: устройства вещают нерегулярно, число пакетов
прыгает от запуска к запуску — это нормально.

---------------------------------------------------------------------
4. ФИЛЬТРЫ В WIRESHARK
---------------------------------------------------------------------
  !_ws.malformed                              — спрятать битые пакеты
  btle.advertising_address == aa:bb:cc:dd:ee:ff  — одно устройство
  btle.advertising_header.pdu_type == 0x00    — только ADV_IND
  btcommon.eir_ad.entry.device_name           — пакеты с именем устройства

---------------------------------------------------------------------
5. ЧТО ВИДНО, А ЧТО НЕТ
---------------------------------------------------------------------
На каналах 37/38/39 ловятся только рекламные пакеты (маячки):
MAC-адрес, тип устройства, имя, данные производителя.

НЕ видно содержимое соединений (клавиатуры, наушники, обмен данными):
после сопряжения оно шифруется и прыгает по 37 каналам данных.

---------------------------------------------------------------------
6. ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
---------------------------------------------------------------------
"Превышен таймаут семафора" / "Access denied":
  прибор занят зависшим процессом. Выполни в командной строке:
    taskkill /IM btle_rx.exe /F
  и запусти заново. (btle_wireshark.bat делает это сам при старте.)

Wireshark открылся, но пакетов нет:
  проверь интерфейс \\.\pipe\btle; закрой всё и запусти bat заново.

Прибор не находится (hackrf_info пустой):
  проверь режим HackRF на PortaPack и кабель USB.

Проверка связи с прибором:
  C:\Users\Kel\Downloads\FIRMWARE_mayhem_nightly_n_261027\utils\hackrf_info.exe
